# 优化工具与浮动编辑窗验证（2026-10-14）

优化图标改为带向内箭头的图片轮廓。沿用已确认的从原图重算规则：原图横排宽高比不超过 2.5、已完成相同的均匀裁剪、空画布及非横排时，优化按钮直接禁用；相同裁剪允许浮点误差容差，不重复编码。默认横排针对 9:16 的自动裁切继续按原规则处理，仍可显式重新均匀裁剪所有原图。

编辑窗从双击位置打开，可拖动标题栏，并在窗口边界内停留。移动反馈每帧合并一次，不改裁剪、不编码。指针离开弹窗或捕获丢失时继续跟随；拖动后的释放点击不触发关闭或背后的其他控件。点击应用内编辑窗外的区域、键盘激活外部控件或切换模块时关闭；先提交已修改的裁剪，未触摸的 50px 预填保持未应用。X 使用对称 SVG 与无内边距的居中按钮。保存失败仍沿用“未保存 / 重试”流程。

进度弹窗采用紧凑的图标标题、蓝色圆角活动条及真实裁剪/保存/预览标记。蓝条在轨道内往返，不在动画起末帧消失；未知时长没有百分比值，实际处理完成才显示 100%。系统减少动态效果时停止活动动画。关闭按钮处理中为禁用浅灰，失败后为可点击中性灰，成功“完成”才使用蓝色。

159/159 测试、构建、`smoke:desktop`、`smoke:ui`、`smoke:recovery`、`smoke:optimization`、`smoke:png-budget` 通过。UI 检查用原生鼠标验证编辑窗拖动和边界、X 两轴居中、拖动不应用 50px、不编码、外部点击提交 37px 并关闭、关闭重开保留裁剪、无需优化按钮禁用、实际完成才结束进度。额外注入一次预览失败，验证已完成的裁剪/保存标记与中性关闭按钮；日志中的“测试：预览生成失败”为预期注入，不是未处理的生产异常。
