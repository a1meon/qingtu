# 图片下方参数与显示区域操作

按 2026-10-17 最新反馈，裁剪、分割、旋转参数框默认居中跟随图片下方，间距 10 px。面板开关不参与画布拟合或缩放限制，不再寻找侧边空位，也不在显示区边缘折返。面板通过 portal 固定定位到文档，允许越过画布和显示区域、覆盖相邻界面，超出部分仍能点击。顶部短横条保留手动拖动及方向键移动，不限制在显示区内。隐藏模块时隐藏 portal，点击参数不取消图片选择；裁剪手势继续冻结视图和控制位置。

显示区下方的信息栏包含缩小、当前实际显示百分比、放大、拖手和平移复位。普通滚动平移，Ctrl/Cmd＋滚轮围绕鼠标所指位置缩放；拖手模式、按住空格拖动或鼠标中键拖动可以平移整个视图。画布、图像、选择/裁剪框和参数锚点一起更新，操作按钮保持固定大小。复位恢复适应画布的视图。手动视图状态只在组件内保存，不修改源图、画布像素、图像位置或导出设置，也不触发保存与编码。编辑手势期间暂停视图导航；平移后的尾随点击不会关闭参数或误选图像。

验证：`npm run smoke:view-navigation` 检查越界参数的实际点击、三种面板开关尺寸不变、按钮缩放、鼠标锚点、拖手/空格/中键平移、复位、保存/编码次数不变，以及放大后的图像拖动坐标；`npm run smoke:floating-editor` 检查 400–1280 宽度的下方定位、面板移动和输入命中。全部使用隐藏且完全离屏的 Electron，并回归裁剪、分割、选中、旋转与完整 UI。复位按钮在参数框经过它时仍保持可点击。证据保存在 docs/viewport-navigation-validation/，运行日志位于 artifacts/viewport-navigation-*.log。
