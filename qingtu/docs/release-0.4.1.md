# 轻图 0.4.1

处理提速：移除大 PNG 重复无损编码，直接复用未变换且符合预算的原图，缓存有界 PNG 编码结果，跳过排队中的旧预览参数；正式导出保持完整执行。

实测用户 5504 × 3072 PNG 首次处理 17.5 → 9.4 秒，10 MB 导出逐字节一致。再次仅改为 9 MB 的核心引擎处理约 10 ms，界面响应还包含防抖和缩略图。详见 performance-0.4.1.md。

沿用 0.4.0 已确认的蓝色界面和动效，默认空队列、10 MB、PNG、空状态 4K。导入后尺寸仍采用原图，支持原图/对比/结果、收起右栏与底部图片队列。

53 项测试、原生 Electron 回归/UI 烟测通过。分发产物位于 release/，提供 Apple Silicon / Intel Mac DMG 与 ZIP、Windows x64 ZIP。Mac 未开发者签名/公证；Intel Mac 和 Windows 为交叉构建，尚未实机运行。
