# 轻图 0.5.5

更新检查使用发行仓库的签名稳定清单，固定路径为 updates/stable/lite-{platform}-{arch}.json；网络请求失败时使用公开正式发行页解析版本，再读取对应版本的签名清单。版本、平台、Ed25519 签名、文件大小和 SHA256 均继续验证；签名错误直接拒绝。整个新通道不请求 Gitee API，保留后台缓存、退避及手动检查入口。

Mac 使用 AppKit 原生 standardWindowButton 的关闭、最小化和缩放按钮，集成在现有工具栏左侧，没有额外应用名称行。保留透明背景和圆角、全屏行为及关闭前保存。以固定上游源码归档和哈希重建 Neutralino，两种 Mac 架构均构建成功。

新通道 Mac 更新使用签名 ZIP：下载后保存项目，校验归档、路径、bundle ID、版本及代码签名，再由独立助手等待旧进程退出，以 renameatx_np(RENAME_SWAP) 原子交换应用，启动新版本并等待带随机令牌的健康握手。正常启动失败会交换回旧版；成功后清理旧包和事务。进程/断电中断后健康新版本可完成遗留事务。若交换后新版本不能启动且看门狗也被强制终止，旧应用仍保留在私有暂存目录，但不宣称能自动从所有断电状态恢复。

旧 lite-darwin 清单继续指向 DMG，新增 lite-auto-darwin 签名 ZIP 清单供新客户端使用。保留全部 0.4.x 兼容桥接附件。0.5.4 及更早的已安装客户端仍含旧 API 代码；API 完全限流时需一次修复安装到本版本，此后进入新通道，不需要每次手动去网站下载。Windows 0.5.2 的旧前端按钮问题同样需一次覆盖安装。覆盖安装无需卸载，保留项目。

已通过 322 项 Node 测试、284 项轻量测试、Go 测试及 Windows 测试程序交叉编译，13 项既有桌面/界面/画布/裁剪/分割/恢复/优化/导出质量检查。隐藏 Chromium 验证两个平台共 16 种布局和实际更新按钮鼠标行为。隐藏原生 Cocoa 验证系统按钮、关闭委托及完整内容区。真实隐藏 WebKit 完成原生助手准备、原子交换、健康重启、项目/原图保留及事务清理；真实 0.4.8→0.4.9→0.5.5 两阶段迁移也通过。Documents 测试位置的旧 Sparkle 曾阻塞在内核 renameatx_np；隔离 /tmp 重跑完成，未改动用户安装应用。

pack:release 构建 20 个附件，共 313,204,545 字节。五份轻量签名清单、四份 Sparkle 归档签名及全部 SHA 校验通过。Windows 安装包四个最终载荷与构建目录逐字节一致。本机为 Apple Silicon，未在真实 Windows 或 Intel Mac 执行本版本。

发行前现存 0.5.3、0.5.4 公开附件共 625,514,024 字节，预计加本次为 938,718,569 字节。公开文件总和不等于服务器实际配额统计，以上传响应为准。最早 0.5.3 已重新匿名下载完整 18 文件并逐字节校验，备份位于 release/archive-v053；仅在空间不足且执行时确认后删除。
