# 精确旋转与滚动平移

旋转面板支持小数角度输入与 0.1° 滑块，保留左右 90° 快捷操作和还原方向。输入或按住滑块时只做轻量预览，松开、Enter、失焦和正常关闭才提交。角度调整期间冻结参数框的位置；指针丢失捕获后继续通过 document 跟踪，Escape 可取消滑块手势。

源图的已有 `rotation` 仍是整 90° 的像素坐标置换。新增 `angle` 是裁剪和尺寸变换之后、以图片中心为轴的任意旋转，因此不用破坏原始副本或重写拆分窗口。预览、缩略图与最终 Sharp 合成都应用该变换，缓存键包含角度。最终输出在旋转后裁取画布交集，能保留原矩形之外旋入画布的角。选择、裁剪和分割框跟随旋转，拖动使用逆旋转坐标；拆分子图的中心也在父图平面上旋转，保留布局记忆。

普通滚轮/触控板滚动现在平移显示区，不改变缩放比例；Shift＋纵向滚动可横向移动。Ctrl 或 Cmd＋滚轮才围绕鼠标缩放。加减、比例、拖手和复位移到显示区下方已有的信息栏，保持原行高，不遮挡图片。缩放和平移依旧只改变显示状态，不保存或编码图片。

验证入口：`npm run smoke:precise-rotation`、`npm run smoke:view-navigation`。测试真实小数输入、滑块按住不保存/编码、导出像素、重开恢复、混用 90°、还原、45° 图片上的裁剪拖动、分割，以及普通滚动平移、修饰键缩放和控制条不覆盖显示区。全部使用隐藏且完全离屏的 Electron；另回归原有裁剪、分割、选择、旋转、浮层与完整 UI。

验证结果：285 项 Node 测试、构建和上述离屏交互检查通过。保存队列按输入修订号串行提交，旧保存不覆盖较新的未提交预览；角度舍入后重新规范化；旋转后输出使用未舍入的图片中心，避免奇数拆分偏移。验证截图和报告保存于 docs/precise-rotation-validation/。
