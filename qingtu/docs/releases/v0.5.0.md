轻图 0.5.0 支持 Windows x64、Apple Silicon Mac 和 Intel Mac。

- Windows 直接下载并运行 `Qingtu-0.5.0-win-x64.exe`。Mac 下载与芯片对应的 `mac-arm64.dmg` 或 `mac-x64.dmg`，打开后将轻图拖入「应用程序」。
- 从 0.4.9 及更早版本升级，请从本页下载对应的完整安装包，安装前退出轻图。
- 0.5.0 的桌面更新器优先访问腾讯云 CNB，连接或附件校验失败时切换到 GitHub。同平台的本地旧包与补丁匹配时，只下载增量补丁。首次安装、清理过旧包或跨越补丁基线时，会自动下载完整包。
- 两个平台都验证更新清单和安装包的完整性。更新在用户确认后下载，等待点击「重启并更新」才安装。
