# 轻图 0.4.2 当前规格

## 桌面更新

品牌旁显示可点击的版本号。桌面启动检查，发现新版先询问，确认后下载，完成后再次确认重启安装；离线启动无提示，版本入口可手动检查/重试。支持 Gitee 公开发行仓库和国内 HTTPS 更新源。没有真实地址时保持未配置状态；浏览器提示使用桌面版。Mac 正式自动安装需要签名，Windows 使用 NSIS 安装版。详见 auto-update.md。

## 处理性能

符合预算、同格式且未调整尺寸的 JPG/PNG 直接复用原文件。大 PNG 只做一次全色无损编码尝试。编码结果按原文件内容、输出尺寸和质量缓存，仅缓存填充前的压缩字节，最多 64 MiB / 256 项；目标大小变化仍按本次有效预算精确填充。缓存不能跨图片或像素尺寸复用。实时预览只保留尚未开始的最新参数任务，已运行任务完成后继续；正式导出不被后续预览取消。

## 预览修正

处理尚未完成时右侧仅显示等待状态；不把原图作为临时处理结果。直接保留原文件时标记“处理后 · 未改动”。原图与实际导出文件按同一原图预览边界、线性采样和颜色空间生成缩略图。对比模式原图层的留白/透明区域使用预览背景，防止下方的处理后画面漏入原图一侧。

Mac / Windows 本地图片处理工具。默认空图片队列、10 MB、PNG 格式、100% 缩放。空状态与清空重置后尺寸显示 3840 × 2160；导入图片后按原图像素显示。底部图片队列与等尺寸加号；支持文件选择、拖入、批量导出、移除、等比或独立宽高修改。主界面保持简短标签。

## 体积与格式

- 有效输出字节数为 min(用户设定大小, 原图字节数)。原图大于设定值时压至设定值；原图小于设定值时，修改分辨率仍保持原文件字节大小，不膨胀到 10 MB。
- 优先使用像素不变的优化；重采样后的 PNG 无损结果能满足大小时直接使用。无法满足时搜索最高可用编码质量，不再因为无损编码太大就直接失败。JPEG 编码与 PNG 调色板量化可能改变像素，不宣称始终无损。
- 目标大小允许整数 MB / KB。1 MB = 1,048,576 字节，1 KB = 1,024 字节。编码后中性填充仅补足有效预算，不补至超过原图的用户设定值。客观无法满足的极小预算仍报明确中文错误。
- 导出格式：自动、JPG、PNG。自动对 JPG 保留 JPG，对 PNG 优先 PNG；不透明 PNG 超出预算时可转 JPG，透明图片保持 PNG。WebP 输入转换为 JPG 或 PNG。显式 JPG 对透明背景使用白底。
- EXIF 方向在尺寸/格式转换中归一化。原文件与已有输出不覆盖，重名追加编号。

## 预览与风格

原图、对比、处理后三种查看方式。分割线事件按 requestAnimationFrame 合并，局部 CSS 更新，不触发整页 React 渲染；取消分割线插值动画，避免拖动滞后。拖动期间缓存画布边界。

采用已确认的蓝色 Duolingo 风格设计：左侧纯图标功能栏、悬停/聚焦名称提示、中央蓝色折角图片角色和大虚线拖入区、右侧可收起导出栏。导入/导出共用 20 px 圆角、5 px 底边的蓝色立体按钮。收起后预览和队列填满空出的宽度，设置/预览/分割线位置保留，不启动新编码任务；折叠控件 inert 且不参与键盘导航。普通图标使用 Phosphor，空状态插画为独立透明 PNG。按钮按下 4 px、释放 190 ms 回弹，菜单弹入 210 ms、侧栏 260 ms、完成图标 400 ms 弹跳，减少动态效果时停用。点击数字输入框或下拉菜单不出现外侧 focus outline。保留键盘菜单选择与明确的菜单高亮。

默认窗口 1280 × 820，Mac 使用原生交通灯，左侧 x=14、y=18，品牌预留 90 px。真实文件状态显示在预览附近，不使用底部状态栏。
