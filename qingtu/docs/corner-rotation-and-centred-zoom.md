# 四角旋转与中心缩放（2026-10-17）

本轮交互覆盖此前的旋转滑块、左右 90° 按钮和视图平移设计。

- 点击图像上方旋转图标后，四个角外侧显示旋转手柄；拖动自由旋转，Shift 吸附到绝对角度的 45° 倍数。Esc 取消本次手势。底部仅保留小数角度输入和还原方向。
- 四角跟随实时角度。旋转工具行在图像边界上下留出手柄操作空间，不改变图像或画布大小；裁剪、分割面板仍使用原有 10px 间距。
- 输入和手柄共用带版本号的角度保存队列。拖动时仅做预览，释放后提交。模块切换、正常关闭先结束手势，再等待保存。按下但尚未移动也分配新版本，避免较早保存完成时清掉正在操作的预览。
- 顶部功能菜单改为 body 中的固定定位浮层，坐标来自实际旋转后的图像边界，不再约束在显示区域内。图像移动时按帧同步菜单位置，取消/结束时恢复临时 DOM 坐标再交给持久状态。非活动模块隐藏所有浮层。
- 底部信息行分别显示画布尺寸、选中图像宽高（画布像素）、视图百分比。图像尺寸可随缩放图像更新；视图缩放不改图像像素尺寸。
- 视图默认/复位为适应画布的 100%，范围 10%–800%；加减按钮和 Ctrl/Cmd+滚轮均围绕固定中心缩放。移除手形、空格/中键拖动和普通滚轮平移。恢复“显示全部”也以画布中心对称扩大拟合范围，避免把画布移到其他位置。
- 画外可见图像仍可点击和拖回；空白处点击维持取消选择及隐藏画外部分的既有规则。实际左右画外点击均做原生鼠标命中回归，未将未复现的消失现象归因于某个未经证实的原因。

验证使用隐藏、离屏、透明 Electron 窗口，不显示或激活原生窗口。覆盖自由/Shift 旋转、四角实际命中、取消、模块切换时持有手柄、旧保存完成时持有手柄、精确角度输入、保存版本竞争、重新打开、实际导出像素、旋转后裁剪/分割、中心缩放、画外点击/拖回、浮层在不同窗口宽度下的布局。构建和 Node 测试输出见 `artifacts/corner-build.log`、`artifacts/corner-unit-tests.log`；关键截图与报告保存在 `docs/corner-rotation-validation`。


## 后续交互修订：悬停光标和压缩命名

四角现为透明的鼠标感应区域，悬停时光标变为方向对应的弧形双箭头；取消常驻的圆形按钮和图标。角度拖动、Shift45°、Esc 取消和保存队列保持原有行为。旋转参数面板收窄至 220px，图片下方间距由 36px 缩为 18px，输入框与复位按钮间距同步收紧。图像尺寸为独立信息，不进入右下角视图加减框。

压缩模块左上角名称可直接编辑：Enter/失焦保存，Esc 取消；下方卡片、当前名称和导出名称同步，重命名不触发压缩。切换图片、导入、导出和删除均先等待名称保存，模块切换及正常关闭接入名称草稿刷新。卡片右键改为“导出该图像、重命名、删除”；单图导出独立于勾选项和当前预览，使用既有导出锁、任务等待和名称/输出格式规则。

本轮验证：287 项 Node 测试、生产构建、隐藏离屏的旋转手势/精确导出/取消/保存竞争、四角实际命中和透明光标、不同窗口宽度的浮动面板、视图尺寸框分离、压缩顶部及卡片重命名、非法名称恢复、单独导出未勾选图片、名称刷新与选择保持均通过。证据在 `docs/hover-controls-validation`。预览地址继续使用 `http://127.0.0.1:4173/`。


## 旋转操作提示与光标（2026-10-18）

进入旋转后，紧凑参数框显示“拖动图片四角旋转”和“按住 Shift · 45° 吸附”。四角使用细小 L 形定位标记，不恢复圆形图标按钮。悬停光标采用约250°圆弧双向箭头，32px画幅、居中热点、深色细线与白色描边，并随角落及图像角度调整方向；箭头留出边缘空间，避免旋转后被光标画幅裁断。已检查浅色及深色背景下的实际SVG渲染。提示和标记不改变图像尺寸、保存或手势流程。


## 滑块与0.1°步进（2026-10-19）

按最新反馈，光标弧线改为约150°，参数卡片移除操作提示；角度/复位行下方新增-180°至180°的滑块，右侧上下箭头每次精确增减0.1°（例如13.75°到13.85°），角度跨边界保持规范化。保留四角拖动、Shift45°与紧凑面板。

验证发现受控范围输入在实时预览重绘后会丢失浏览器原生滑块捕获；相同样式的独立原生范围输入正常，原节点仍连接、启用且聚焦。滑块因此采用固定轨道边界的文档级指针采样，键盘仍使用标准范围输入。拖动仅预览，释放提交，Esc恢复；模块切换和正常关闭使用现有版本化保存队列。已通过0.1°步进/细小数/边界、真实滑块拖动与取消、模块切换持有滑块、四角/Shift/Esc、旧保存竞争、实际旋转导出、不同窗口尺寸，以及287项Node测试。证据见 `docs/rotation-slider-validation`。

补充回归：指针取消后立即使用键盘微调也可正常工作；Esc 取消仅抑制当前仍按住的鼠标事件，pointercancel 直接结束该指针流，避免遗留键盘禁用状态。
