# 轻图

Mac / Windows 本地图片压缩与拼接工具。拖入图片，设置大小或分辨率，预览并导出。压缩模块底部是图片队列，拼接模块底部是整个画布的项目卡片。

本分支实现横排、竖排、紧密宫格、自由画布，以及多项目自动保存恢复和全彩高保真 PNG。实测记录、实际输出与平台验证范围见 [docs/stitch-and-quality.md](docs/stitch-and-quality.md)。本分支尚未发布安装包。

## 使用

- 启动时图片队列为空，大小默认 10 MB，重置后也为 10 MB；可切换 KB。1 MB = 1,000,000 字节，1 KB = 1,000 字节。
- 未导入图片时尺寸显示 4K（3840 × 2160）；导入后显示原图尺寸、100% 缩放。格式默认 PNG，重置后仍为 PNG。
- 左侧纯图标导航，悬停或键盘聚焦显示功能名称；“图像拼接”进入真实工作台。切换模块保留各自图片、设置和预览。右侧设置栏可收起。
- 蓝色立体按钮、按压回弹、菜单浮现、导入入场和完成反馈动效；系统开启减少动态效果时停用动画。
- 使用自动优化，没有模式切换。修改宽度、高度或缩放百分比即可调整分辨率；链条按钮锁定原图比例。
- 导出格式为自动、JPG、PNG。自动优先原 JPG/PNG；不透明 PNG 太大时可用 JPG，透明图片使用 PNG。WebP 可导入，输出为 JPG 或 PNG。显式 JPG 将透明背景合成为白色。
- 预览提供原图、对比、处理后三种查看方式；Mac 顶栏使用系统原生窗口按钮。
- 保留原文件时标记“未改动”。预览分别来自原文件和真实导出文件，使用一致的采样边界；等待结果时不以原图充当结果。
- 选择文件夹后导出。重名文件自动追加编号，不覆盖源文件或已有输出。
- ⌘/Ctrl + O 添加图片；⌘/Ctrl + Shift + S 导出。批量处理可取消后续任务。

## 拼接

- 默认横排等高，竖排等宽，始终等比缩放。宫格按指定行数、每行最多列数排列：每行等高、所有行同宽，末行同样铺满，无空格或空洞；无法容纳或比例超限时提示调整。
- 最终画布宽高均不超过 5999 px，长短边比不超过 2.5；默认长边 5999 px，可修改长边等比调整分辨率。自动布局零间距，所有导出零外边距、矩形边缘，透明棋盘格仅供显示。
- 唯一自动裁切是横排超宽时对其中未手动裁剪的 9:16 图片左右居中裁切。其他比例和竖排、宫格、自由布局超限时提示调整。四张未编辑的 3:4、3:4、9:16、9:16 图片默认输出 5999×2400。
- 自由画布包住全部可见图片内容，内部空隙透明。进入自由画布时保留高度与中心，恢复自动裁切，保留用户手动裁剪；新增图片按现有基准高度缩放，在右侧追加。支持画布内移动、边缘/中心吸附、等比尺寸调整；蓝色选中框贴合图片，始终显示在图片上方。
- 底部卡片展示整个拼图画布，可切换、新建、删除及批量选择项目；顶部不再显示项目标签。添加、选择和移除图片均在画布区域进行，右侧保留布局与导出设置。卡片预览为持久化的小图，不加载其他项目的原图。
- 双击图片打开单图编辑浮层。左右或上下二选一，拖动滑块或输入原图每侧裁剪像素；切换方向从 0 开始，可重置。手动裁剪适用于所有布局，原图副本不变；自由画布保留图片中心和原图缩放比例。已有自动裁切仅在修改后变成手动状态，不会因打开编辑器而固定。
- 横排、竖排、宫格中直接拖动图片换序；自由画布中直接拖动移动位置。滑块与拖动仅更新低分辨率画面，结束后自动保存并计算真实预览；键盘 Alt+方向键换序，方向键移动自由图片，Enter 编辑，Delete 移除。
- 每个拼图项目独立保存图片、布局、位置、尺寸与导出设置，可分别或批量导出。编辑自动保存；桌面保管原图副本，移动原文件仍可恢复；浏览器使用 IndexedDB 保存 Blob，空间不足明确提示“未保存”。项目按需加载，删除项目不删除外部原文件。
- 正常关闭与确认更新重启时，等待导入、导出、手势提交及待保存操作完成。保存失败时保留当前编辑状态并提示重试。

## 体积与画质

输出严格不超过设定大小。符合上限且无需修改的原始文件直接保留；调整尺寸或格式后，可以使用完整的设定预算，以优先保留画质、尽量接近上限。

PNG 先比较全彩无损编码的两种行过滤策略。不能达到上限时，在完整颜色空间中搜索受限像素变化：RGB 每通道最大误差为 2/255，透明度不变，保护平坦区域、平滑渐变和强边缘；候选需通过实际解码后的最大误差、RMSE 校验。照片与纹理样片的原尺寸对比及 PSNR 记录见验证文档。PNG 不再转成最多 256 色的调色板图。该策略是保守的质量下限，并不保证任意原图能达到任意预算；无法满足时明确要求增加上限。

JPEG 仍搜索最高适配质量，透明部分合成为白色。显式 PNG 不改格式、不偷偷降低分辨率。自动格式保留既有不透明图片可选 JPG 的规则。

主流程不添加体积填充，以实际编码文件字节数校验上限。

PNG 未找到高保真候选时提示增加上限；尺寸调整由用户决定。错误不会带 Electron IPC 前缀。所有工作流忽略旧客户端的填充标志，不添加无意义字节凑大小。

未改尺寸且原文件已符合预算时复用原文件。编码缓存限 64 MiB / 256 条；快速修改设置会跳过过时的排队预览，真实导出保留。旧版本的性能记录见 docs/performance-0.4.1.md，它使用旧调色板流程，不能代表本分支的高保真编码耗时。

输入支持单帧 JPEG、PNG、WebP、AVIF、TIFF。单图 100 MB、队列 100 张/500 MB、目标最大 100 MB、总像素不超过 1 亿。不接受动画/多页文件，防止丢失帧。高位深图片暂不支持尺寸或格式转换。

## 自动更新

0.4.5 已通过 Gitee 的 a1meon_admin/halframe-releases 发布。桌面启动检查新版，先询问，再下载并确认重启；离线启动安静，点击版本号可手动检查。Mac 使用 Sparkle、Ed25519 签名更新包及免费 ad-hoc 应用签名，无需 Apple Developer Program；Windows 使用 NSIS。Gitee 大安装包采用经过校验的分片传输。首次安装和发布步骤见 [docs/auto-update.md](docs/auto-update.md)。

## 开发环境

需要 Node.js 22.15 或更新版本，建议 Node.js 24。

```sh
npm ci
npm run dev
```

浏览器预览与桌面共用真实处理引擎。浏览器预览导出会写入 `artifacts/browser-exports/`；桌面版使用原生目录选择器。

```sh
npm test
npm run build
npm run desktop
npm run smoke:desktop
npm run smoke:ui
npm run smoke:recovery
npm run verify:quality -- /path/to/optional-original.png
```

## 打包

```sh
npm run pack:mac        # Apple Silicon DMG / ZIP
npm run pack:mac:intel  # Intel Mac DMG / ZIP
npm run pack:win        # Windows NSIS 安装程序
npm run pack:win:zip    # Windows 完整应用目录 ZIP
```

Windows ZIP 解压后运行「轻图.exe」，保留同目录资源和 DLL。本次开发不构建或发布安装包、不合并 main。签名材料缺失时保留嵌入公钥，由原发布环境在后续发布确认后签名。

桌面分发产物在 `release/`。本分支在 Windows 上执行 Electron 开发构建烟测及关闭重开检查；本次没有 Mac 实机、安装包安装或正式更新签名发布验证。历史发布记录见自动更新文档。

## 验证与结构

- `engine/`：图片编码、纯布局计算、原图合成、原子项目保存、体积与画质校验。
- `desktop/`：Electron 主进程和受限 preload，renderer 无 Node 权限。
- `src/`：压缩工作台、`stitch/` 拼接交互与 IndexedDB 图片 Blob/项目存储、关闭保存协调。
- `tests/`：目标字节、像素、透明度、EXIF、等比尺寸、并发缓存和重名文件保护。
- `design-qa.md`：源视觉与最终实现的检查记录。

样片及图标由内置 Image Gen 生成，工作区保留生成的 PNG 原始资源，`public/samples/*.jpg` 只作为测试素材，不在启动时自动加载。工具栏图标采用 Phosphor Icons，应用图标为生成的蓝色折角图片形象。全部处理在本机进行，不上传图片。
