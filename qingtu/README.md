# 轻图

Mac / Windows 本地图片压缩与拼接工具。拖入图片，设置大小或分辨率，预览并导出。压缩模块底部是图片队列，拼接模块底部是整个画布的项目卡片。

本分支实现固定高度的人物拼接工作流、直接拖动换序、四边及四角关联裁剪、画布上分割、独立布局记忆、多项目自动保存恢复和全彩高保真 PNG。最新规则、真实截图与导出验证见 [docs/portrait-workflow.md](docs/portrait-workflow.md)，提速与原图分割基础见 [docs/split-and-speed.md](docs/split-and-speed.md)。最新源码增加空画布隐藏导出复选框、右侧无底框复选框、拼接默认 30 MB、空白取消选择及选中图越界显示，并修复 Mac 图片解码等待导致的关闭阻塞。底部画布支持双击或右键重命名，导出沿用修改后的名称，取消选择时画布显示大小和位置保持不变；见 [修改与验证记录](docs/canvas-selection-and-mac-close.md)。0.4.8 已联合发布 Windows x64、Mac Apple Silicon 和 Mac Intel；见 [发行与验证记录](docs/release-0.4.8.md)。

## 使用

- 启动时图片队列为空，大小默认 10 MB，重置后也为 10 MB；可切换 KB。1 MB = 1,000,000 字节，1 KB = 1,000 字节。
- 未导入图片时尺寸显示 4K（3840 × 2160）；默认导入后显示原图尺寸、100% 缩放。导入前已设置的尺寸会应用到图片。格式默认 PNG，重置后仍为 PNG。
- 左侧纯图标导航，悬停或键盘聚焦显示功能名称；“图像拼接”进入真实工作台。切换模块保留各自图片、设置和预览；已完成的拼接预览不会因切换而重新合成/编码。右侧设置栏可收起。
- 蓝色立体按钮、按压回弹、菜单浮现、导入入场和完成反馈动效；系统开启减少动态效果时停用动画。
- 使用自动优化，没有模式切换。修改宽度、高度或缩放百分比即可调整分辨率；链条按钮锁定原图比例。
- 两个模块的导出格式只有 JPG、PNG，默认 PNG；旧项目的“自动”转为明确的 PNG。WebP 可导入，输出为 JPG 或 PNG。JPG 将透明背景合成为白色。
- 压缩预览提供原图、对比、处理后三种查看方式；拼接直接在画布编辑，右上角不再切换布局/处理后。两个模块的预览框、底部列表、大小、格式、文件夹与导出按钮保持相同位置。图片和缩略图以白底预览，PNG 导出仍保留透明度；Mac 顶栏使用系统原生窗口按钮。
- 保留原文件时标记“未改动”。预览分别来自原文件和真实导出文件，使用一致的采样边界；等待结果时不以原图充当结果。
- 选择文件夹后导出。重名文件自动追加编号，不覆盖源文件或已有输出。
- ⌘/Ctrl + O 添加图片；⌘/Ctrl + Shift + S 导出。批量处理可取消后续任务。

## 拼接

- 首次使用时点击“打开图片”，单选或多选的图片会进入同一个画布。也可以直接拖入图片，或点击旁边的“新建空白画布”，进入后再点“添加图片”。取消选图、删除最后一个画布或删除全部画布后，都会回到这两个入口。已有项目照常自动恢复。

- 100% 视图会按预览区的宽高等比显示完整画布，仅为当前显示的裁剪／分割控件留位置；普通查看不预留整个编辑面板。窗口变大后自动适配，导出继续使用设置的画布像素尺寸，调整窗口不会重新编码。

- 自由布局中的图片移出预览区后，可以缩小视图或平移，再把淡显的图片拖回画布。调整视图不会改变保存的图片位置、裁剪、大小或导出画布。

- 裁剪下方提供当前边的滑块和原图像素输入，开启关联时两侧一起调整；滑块向回拖到 0 可恢复完整内容，四边及四角直接拖动仍可用。四视优化默认在三张图片中选第 2 张、四张中选第 3 张，顶部裁去 15%，左右各裁 100 个原图像素。可点编号多选、取消或调整每张图片的参数，手动选择随图保存，点击「四视优化」后应用。

- **直接打开单图时，长边在 5999 px 以内就采用原图宽高；超出则整张图等比缩小到长边 5999 px**。通常的空白画布初始高度为 2495 px。向已有画布继续添加图片时，按画布高度等比排列。横排自动宽度随图片总宽变化，普通拼接画布的宽度最多为高度的 2.4 倍且不超过 5999 px。达到上限后，继续放大图片只改变图片本身，越界内容淡显，最终只导出画布区域；不会把其他图片缩小或悄悄改掉原图裁剪。
- 支持四张独立图（正脸、侧脸为 3:4，正面全身、背面全身为 9:16），也支持两张已合成图（正脸＋侧脸、正面全身＋背面全身）。不自动识别角色或去头：选中正面全身图，在上下不联动时拖动上边裁剪即可去掉头部。手动裁去顶部时，其余像素保持原有缩放比例，图片底边留在原位。
- 普通拼接画布每边为 1–5999 整数像素，长短边比不超过 2.5。直接打开单张全景图可保留原图比例，导出长边仍以 5999 px 为限。自动宽度封顶后保留越界内容供编辑；非法手动尺寸或过窄布局明确提示并阻止导出，不补透明边来掩盖冲突。右侧保留 2.4:1、21:9、16:9、4:3、1:1 预设。单张原图可随时选「原图比例」恢复导入尺寸，「自定义」可找回上次手动输入的尺寸。宽高默认联动，点击中间的链条可分别调整两边；手动设置后，继续导入图片、切换布局和导出都使用指定宽高。
- 横排、宫格、竖排首次进入时自动排列并贴合内容；手动指定过画布时，在该画布内等比排列。横排等高、竖排等宽；宫格每行等高、各行同宽，无空格或空洞，无法容纳时提示调整，不自动裁切图片。四种布局分别自动记住最后的**画布尺寸、图片位置和尺寸**，切回时恢复，点击当前布局不重排；自由首次保留当前变换。每次导入也会按各布局自己的相对位置重新贴合已访问的布局，避免切回后遗漏新图。裁剪与顺序仍由项目共用。
- 横排、竖排、宫格中，拖动时图片跟随鼠标，指向另一张图片会出现目标框，松手后两张图片交换位置。在空白处或原图位置松开，或按 Esc 取消，图片都会回到原位。换序保留横排图片的裁剪、尺寸与原始导入顺序记录，不重置编辑。自由布局中拖动是移动，保留吸附。四种布局均支持四角与四边共八个缩放手柄，默认等比；按住 Shift 可独立调节宽高。画布高度保持固定，上下超出部分由画布裁切。缩放默认吸附到画布边缘、其他图片边缘和中心线，显示轻量辅助线；吸附不改变默认等比规则。画布外以 22% 透明度显示，选中框在前景；淡显、选中框和手柄都不进入导出。
- 所有导出边缘为矩形，无额外外边距、圆角遮罩或棋盘格；PNG 保留画布留空处和源图透明度，白色预览底仅用于显示。JPG 将透明区域合成为白色。
- 底部“图像”卡片展示整个画布，点击缩略图切换编辑，左上角勾选框独立选择要导出的画布，支持单选、多选及全选/取消全选。默认导出全部非空画布，手动选择后只导出勾选项；右侧按钮显示实际数量，未勾选时禁用。空画布不可勾选，切换画布或模块保留本次选择，重开应用恢复默认全选。右键卡片仍可直接单独导出或删除，删除前确认；列表右上角可确认删除全部，完成后回到“打开图片”和“新建空白画布”。画布内不再显示添加/删除按钮；使用拖入或 ⌘/Ctrl+O 继续导入，Delete 移除选中图片。手动创建的空画布仍可点击“添加图片”，无画布时拖入图片会自动新建画布。右侧保留布局与导出设置，卡片小图持久化且不加载其他项目原图。
- 横排「四视优化」先应用已选图片的特殊裁剪，再按等高横排计算整组宽高比。总比例在 2.4:1 以内时，保留其余图片的完整内容。超过 2.4:1 时，由其余图片按相同比例左右对称裁剪。自动画布贴合内容，手动设置的较窄画布将整排居中。下拉面板右上角的问号可查看操作说明。
- 画布右上角仅放置各自有背景的重置与“四视优化”，优化位于最右侧，采用简洁的向内收拢线条图标。优化弹窗显示真实裁剪、保存、布局预览阶段；保存与清晰布局预览完成后弹窗直接关闭，即可继续编辑，体积在后台计算。MB 就绪后显示真实文件大小，导出等待实际编码并验证上限。处理中关闭为禁用浅灰色，失败关闭为白底中性色并保留错误。重置先确认，确认按钮沿用主按钮蓝色，取消为白底。右侧布局依次为横排、宫格、竖排、自由。
- 选中图片，上方显示“裁剪／分割”。双击、右键编辑也打开同一套下方控件，不再弹出可拖动编辑窗。裁剪直接拖动图片四边及四个角，保留原图像素数值，下方滑块控制当前边并可拖回 0 恢复内容；下方按“左／联动／右”和“上／联动／下”排列。左右默认联动，上下默认独立，已有明确设置保留；仅高亮当前编辑方向组，当前组开启联动后两侧按钮同时选中，同步裁剪；切换方向不改变另一组的联动设置。裁剪编辑框在图片下方居中，靠近窗口边缘时保持可见。向外拖可恢复可用原图，四边裁剪可以同时保留。横排裁剪保持图片中剩余内容的缩放比例，宽度变化时重新排紧，同步更新自动画布宽度和尺寸显示，宽度仍受 2.4:1 上限约束；手动画布保持尺寸。拖动时固定视图缩放和画布原点，避免预览自动适配造成指针跳动。角点分别遵守左右、上下联动；裁剪手柄从第一个原图像素开始按拖动距离调整，无边缘吸附。选中手柄后，方向键可按一个原图像素微调。关联按图片保存，纯设置变更复用编码结果。未编辑图片左右各预填 50 px，未修改不应用；直接拖动从实际裁剪开始，不带入预填值。首次切换到上下边会清掉未应用的左右预填。松手或数值修改后自动保存；拖动中 Escape 取消本次拖动，平时点击控件外或 Escape 关闭，正常退出会保存未松手的最新裁剪；重置清除该图四边裁剪。
- 拖动旋转角点或角度滑块时，按住 Shift 可按 15° 步进，松开后可继续自由旋转。
- 点击图片上方“分割”，在完整原图上拖动分割线或设置数值，拖好分割线后按回车或点击“确认”完成分割。水平横线分上下，垂直竖线分左右；确认前不改变项目，取消恢复原裁剪和位置。分割忽略已有裁剪并保留原图中心、缩放比例；两张共用不可变原图副本，确认不编码、不复制大图，可继续分割、缩放和裁剪。其他布局记忆同步替换父图位置，保存恢复使用同一源区域。
- 点击右上角的重置按钮会将分割的切片合回原图，清除裁剪、恢复导入时的尺寸和顺序。画布视图居中回到 100%。重置成功提示会在 15 秒后自动消失，与导出成功提示一致。新导入图片记录导入时的显示宽高，自由布局恢复该大小并保留当前中心；横排、宫格、竖排重新衔接排列，各布局记住的放大状态也会清除。没有尺寸记录的旧图按当前画布高度等比恢复；拆分图片继承原图相应部分的导入尺寸。保留布局、手动画布和导出设置，自动画布宽度按既有规则更新。没有顺序记录的旧多图项目须由用户提供真实顺序，应用不会猜测。
- 拖动、缩放及裁剪边在 requestAnimationFrame 中只更新低分辨率画面，结束后自动保存并计算真实预览；键盘 Alt+方向键换序并按当前预设重新排列，自由模式下调整叠放顺序；普通方向键移动图片，Shift+方向键移动 10 px，Enter 编辑，Delete 移除。聚焦裁剪边时，对应方向键按 1 个原图像素调整，Shift 按 10 px 调整。
- 主按钮“导出 X 张图像”默认导出全部有内容的画布项目，空画布跳过且不计入 X；右键卡片可分别导出。每个项目独立保存图片、布局、位置、尺寸与导出设置。卡片和缩略图禁止原生拖动，内部缩略图文件不会被当作原图导入其他项目。编辑自动保存；桌面保管原图副本，移动原文件仍可恢复；浏览器使用 IndexedDB 保存 Blob，空间不足明确提示“未保存”。项目按需加载，删除项目不删除外部原文件。
- 正常关闭与确认更新重启时，等待导入、导出、手势提交及待保存操作完成。保存失败时保留当前编辑状态并提示重试。
- 大幅面拼接优先尝试快速全彩无损 PNG，已满足上限即使用；简单平坦图片继续精细无损压缩，超限时在当前宽高下尝试高保真编码。快速文件可能比最大压缩等级略大，像素和透明度完全相同。相同处理结果可直接复用为独立导出任务，不再重读原图和编码。
- 已有项目保留原图、顺序、裁剪和图片变换；旧自动画布沿用保存的高度，宽度按新上限封顶，越界内容保留。手动画布保留指定尺寸，无效设置仍可恢复并修改。不删除原图或旧清单备份。

## 体积与画质

两个板块均以设置的大小为上限。两个板块均将导出长边限制在 5999 px。直接拖入或打开单张图片，限内画布采用原图宽高，超限时整图等比缩小。对于 JPG 和 PNG，尺寸与格式相同、画面没有编辑且文件符合上限时，直接导出原文件。调整尺寸、变更格式或编辑画布后，按实际结果编码。

PNG 先比较全彩无损编码的两种行过滤策略。不能达到上限时，在完整颜色空间中搜索受限像素变化：RGB 每通道最大误差为 2/255，透明度不变，保护平坦区域、平滑渐变和强边缘；候选需通过实际解码后的最大误差、RMSE 校验。颜色较少的图也会尝试无损调色板。仍超限时，在指定宽高下逐步减少颜色，按实际编码字节挑选调色板。很小的预算可以简化局部细节，预览展示实际编码结果。超大画布配极小上限时，设置框显示可选的 KB 起点。

JPEG 预算充足时使用 4:4:4 保留细彩色边缘；预算不足时用快速编码定位质量范围，比较解码后的像素误差，再用 mozjpeg 在局部范围细化。每种策略搜索最高适配质量，透明部分合成为白色。导出使用指定的像素宽高，并校验文件的实际字节数。

底栏中央显示编码类别和实际文件体积。导出文件变大时，将鼠标移到「增加」右侧的问号即可查看格式转换、拼接或像素尺寸变化等原因。

PNG 编码误差以设定宽高的像素为基准。预览、单张和批量导出使用相同规则。

未改尺寸、格式且原文件已符合预算时直接复用原文件，不运行压缩编码；明确指定的尺寸或格式修改仍执行。PNG 像素分析只计算一次，复用最佳无损过滤策略并减少候选编码。编码缓存限 64 MiB / 256 条；快速修改设置会结束过时预览的后续合成/搜索，真实导出保留。实测 PNG 照片/纹理约快一倍，详细时延与像素差异见验证文档；大图第一次尝试极低上限仍可能较慢。旧版 docs/performance-0.4.1.md 使用调色板流程，不能代表本分支画质与耗时。

输入支持单帧 JPEG、PNG、WebP、AVIF、TIFF。单图 100 MB、队列 100 张/500 MB、目标最大 100 MB、总像素不超过 1 亿。不接受动画/多页文件，防止丢失帧。高位深图片暂不支持尺寸或格式转换。

## 自动更新

0.5.0 起使用腾讯云 CNB 主源和 GitHub Releases 备用源。首次安装下载一个 Windows EXE 或与芯片对应的 Mac DMG。应用内更新会优先使用匹配的增量补丁，缺少基线时下载完整 EXE 或 ZIP。旧版用户可从 Gitee 发行说明的入口下载 0.5.0 并覆盖安装。详见[发布手册](docs/auto-update.md)。

```sh
npm ci

```

`npm run dev` 默认只监听本机。开发预览通过本机服务处理图片，导出时也会在 `artifacts/browser-exports/` 保留文件。macOS 和 Windows 桌面版都使用系统设置的「图片」目录，首次使用默认位置导出时会在其中创建「轻图output」文件夹。两个模块分别沿用各自上次成功导出的目录。悬停或点击左侧目录框可以查看完整路径，点击右侧「选择目录」可以更换目录。支持目录授权的浏览器会在首次按默认位置导出时打开系统「图片」位置，授权后写入「轻图output」；也可以直接选择其他输出目录。“导出历史”按模块平铺显示文件缩略图、文件名、时间和目录，每页 30 条。悬停缩略图可略微放大预览。文件或目录被删除或移动后，相应记录会置灰。导出完成提示也保留“打开文件夹”。

`npm run build` 生成的静态网页版可通过 `npm run preview` 验证。首次处理图片时，浏览器按需加载随应用打包的图像引擎。原图在浏览器内处理，画布保存在 IndexedDB，导出文件进入浏览器的下载位置。两个页面修改同一画布时，后保存的页面可以将编辑另存为副本。

Windows ZIP 解压后运行「轻图.exe」，保留同目录资源和 DLL。本轮已构建并发布 0.4.8，保留当前开发分支，不合并 main。沿用原有更新签名材料，缺失时停止发布，不旋转公钥。

桌面分发产物在 `release/`。本轮在 Apple Silicon Mac 执行开发版原生检查与交叉构建。Windows 安装器原生安装、Intel Mac 原生运行仍需对应实机验证；发布与签名验证状态见各版本发行记录。

## 验证与结构

- `engine/`：图片编码、纯布局计算、原图合成、原子项目保存、体积与画质校验。
- `desktop/`：Electron 主进程和受限 preload，renderer 无 Node 权限。
- `src/`：压缩工作台、`stitch/` 拼接交互与 IndexedDB 图片 Blob/项目存储、关闭保存协调。
- `tests/`：目标字节、像素、透明度、EXIF、等比尺寸、并发缓存和重名文件保护。
- `design-qa.md`：源视觉与最终实现的检查记录。

样片及图标由内置 Image Gen 生成，工作区保留生成的 PNG 原始资源，`public/samples/*.jpg` 只作为测试素材，不在启动时自动加载。工具栏使用 Phosphor Icons 及自绘 SVG，压缩导航采用折角图片图标，应用图标为生成的蓝色折角图片形象。全部处理在本机进行，不上传图片。
