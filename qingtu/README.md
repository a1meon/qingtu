# 轻图

Mac / Windows 本地图片压缩与拼接工具。拖入图片，设置大小或分辨率，预览并导出。压缩模块底部是图片队列，拼接模块底部是整个画布的项目卡片。

本分支实现导入及图片缩放后自动贴合画布、独立布局记忆、横排/竖排/紧密宫格排列、自由移动与缩放、原图拆分，以及多项目自动保存恢复和全彩高保真 PNG。最新缩放规则、截图与实际导出见 [docs/resize-canvas.md](docs/resize-canvas.md)，导入贴合见 [docs/content-canvas.md](docs/content-canvas.md)，其他交互见 [docs/canvas-interaction.md](docs/canvas-interaction.md)，提速与拆分实测见 [docs/split-and-speed.md](docs/split-and-speed.md)。本分支尚未发布安装包。

## 使用

- 启动时图片队列为空，大小默认 10 MB，重置后也为 10 MB；可切换 KB。1 MB = 1,000,000 字节，1 KB = 1,000 字节。
- 未导入图片时尺寸显示 4K（3840 × 2160）；导入后显示原图尺寸、100% 缩放。格式默认 PNG，重置后仍为 PNG。
- 左侧纯图标导航，悬停或键盘聚焦显示功能名称；“图像拼接”进入真实工作台。切换模块保留各自图片、设置和预览；已完成的拼接预览不会因切换而重新合成/编码。右侧设置栏可收起。
- 蓝色立体按钮、按压回弹、菜单浮现、导入入场和完成反馈动效；系统开启减少动态效果时停用动画。
- 使用自动优化，没有模式切换。修改宽度、高度或缩放百分比即可调整分辨率；链条按钮锁定原图比例。
- 两个模块的导出格式只有 JPG、PNG，默认 PNG；旧项目的“自动”转为明确的 PNG。WebP 可导入，输出为 JPG 或 PNG。JPG 将透明背景合成为白色。
- 压缩预览提供原图、对比、处理后三种查看方式；拼接直接在画布编辑，右上角不再切换布局/处理后。两个模块的预览框、底部列表、大小、格式、文件夹与导出按钮保持相同位置。图片和缩略图以白底预览，PNG 导出仍保留透明度；Mac 顶栏使用系统原生窗口按钮。
- 保留原文件时标记“未改动”。预览分别来自原文件和真实导出文件，使用一致的采样边界；等待结果时不以原图充当结果。
- 选择文件夹后导出。重名文件自动追加编号，不覆盖源文件或已有输出。
- ⌘/Ctrl + O 添加图片；⌘/Ctrl + Shift + S 导出。批量处理可取消后续任务。

## 拼接

- 首次使用没有画布，底部只有“新建画布”卡片；点击后才创建。删除最后一个或删除全部后保持无画布，重新打开仍为空。已有项目照常自动恢复，不会为展示空状态删除已有内容。

- **每次导入图片都会重新贴合画布**，包括已手动设置宽高或预设的画布。计算全部图片的外接范围，保留相对位置、缩放比例和裁剪，再整体等比缩放、移到画布起点。新项目默认长边 5999 px；手动修改尺寸后，后续导入使用该布局最后设置的长边。严格 2.5:1 时使用 5:2 整数尺寸，默认 5995×2398；画布不锁定为此比例。空画布暂显示该尺寸，导入后按内容计算。
- 每边须为 1–5999 整数像素，长短边比不超过 2.5。完整内容超限时保留全部图片并明确提示、阻止导出，不自动裁切、拉伸或增加透明填充。可手动调整画布或布局。右侧保留 2.5:1、21:9、16:9、4:3、1:1 预设及独立宽高输入；选择后保留图片变换，直到再次导入才重新贴合。
- 横排、宫格、竖排首次进入时自动排列并贴合内容；手动指定过画布时，在该画布内等比排列。横排等高、竖排等宽；宫格每行等高、各行同宽，无空格或空洞，无法容纳时提示调整，不自动裁切图片。四种布局分别自动记住最后的**画布尺寸、图片位置和尺寸**，切回时恢复，点击当前布局不重排；自由首次保留当前变换。每次导入也会按各布局自己的相对位置重新贴合已访问的布局，避免切回后遗漏新图。裁剪与顺序仍由项目共用。
- 所有排列中都能直接拖动图片，吸附到其他图片或画布边缘/中心；八个手柄默认按当前比例缩放，按住 **Shift** 可独立调整宽高。画布内正常显示，越界内容以 22% 透明度显示并仍可选择、拖动；导出只保留画布内的部分，越界原图仍完整保存在项目中。选中框与手柄显示在图片上方。
- 继续添加时先按首张现有图片的高度等比缩放，在现有图片最右侧依次追加，再将全部内容重新贴合画布，不重排已有图片。**自动贴合的画布随图片缩放而扩大或收缩**，缩放结束后按全部图片的实际边界更新，不把图片放大回原长边。手动选过预设或输入宽高后，图片缩放保持该画布尺寸。单纯移动图片仍可拖到画布外，画布不变；再次导入会将越界内容一起纳入。手动移动产生的内部空隙保留透明，比例只受 2.5 上限约束，并不锁定。
- 所有导出边缘为矩形，无额外外边距、圆角遮罩或棋盘格；PNG 保留画布留空处和源图透明度，白色预览底仅用于显示。JPG 将透明区域合成为白色。
- 底部“图像”卡片展示整个画布，可切换、新建，无复选框。右键卡片可单独导出或删除，删除前确认；列表右上角可确认删除全部，完成后只剩“新建画布”。画布内不再显示添加/删除按钮；使用拖入或 ⌘/Ctrl+O 继续导入，Delete 移除选中图片。手动创建的空画布仍可点击“添加图片”，无画布时先新建。右侧保留布局与导出设置，卡片小图持久化且不加载其他项目原图。
- 横排“一键优化”从完整原图重新计算，每张按相同百分比左右居中裁剪，替换旧裁剪并横排铺满**当前画布比例**，画布尺寸保持不变。例如画布改为 2:1，就按 2:1 优化。原图横排比例不大于画布宽高比、已完成同样裁剪或非横排时禁用。默认 5995×2398 的四张示例仍各侧裁约 2.38%；2:1 画布各侧约 11.90%。
- 画布右上角仅放置各自有背景的重置与“一键优化”，优化位于最右侧，采用自绘的裁边确认图标。优化弹窗显示真实裁剪、保存、布局预览阶段；保存与清晰布局预览完成后弹窗直接关闭，即可继续编辑，体积在后台计算。MB 就绪后显示真实文件大小，导出等待实际编码并验证上限。处理中关闭为禁用浅灰色，失败关闭为白底中性色并保留错误。重置先确认，确认按钮沿用主按钮蓝色，取消为白底。右侧布局依次为横排、宫格、竖排、自由。
- 画布中右键图片可编辑或删除，双击图片在鼠标位置打开单图编辑浮层，靠近边缘时自动避让。可拖动标题栏移动编辑窗，始终限制在窗口内；点击应用内浮层外的区域自动关闭并提交已改动的裁剪，关闭图标居中。左右或上下二选一，拖动滑块或输入原图每侧裁剪像素；切换方向从 0 开始，可重置。未编辑图片每侧预填 50 px，修改或点“完成”才应用，直接关闭或退出应用不应用预填。已有裁剪状态保留；手动裁剪适用于所有布局，原图副本不变，自由画布保留图片中心和原图缩放比例。
- 单图编辑选择“拆分”后，分割线直接叠在画布中的完整原图上，编辑窗只保留方向、数值和确认：水平横线分成上下，垂直竖线分成左右；默认居中，拖动分割线或输入原图像素，确认后才生成两张独立图片。按完整原图拆分并忽略已有裁剪，保持中心与原图缩放比例恢复完整内容；原有 Shift 宽高比例保留。两张共用一份不可变原图副本，确认不编码、不复制大图；支持继续拆分、移动、缩放和裁剪，保存恢复使用同一源区域。同步替换其他布局记忆中的父图位置；拖线不编码、不保存，关闭未确认的拆分不改变项目。
- 右上角重置恢复裁剪和真正导入顺序，保留画布、布局与导出设置，以及各图原始缩放与中心（包括 Shift 调整的宽高比例）。新项目自动记录导入顺序。没有该记录的旧多图项目须由用户提供真实顺序，应用不会猜测。
- 拖动、缩放及滑块在 requestAnimationFrame 中只更新低分辨率画面，结束后自动保存并计算真实预览；键盘 Alt+方向键换序并按当前预设重新排列，自由模式下调整叠放顺序；普通方向键移动图片，Shift+方向键移动 10 px，Enter 编辑，Delete 移除。
- 主按钮“导出 X 张图像”默认导出全部有内容的画布项目，空画布跳过且不计入 X；右键卡片可分别导出。每个项目独立保存图片、布局、位置、尺寸与导出设置。卡片和缩略图禁止原生拖动，内部缩略图文件不会被当作原图导入其他项目。编辑自动保存；桌面保管原图副本，移动原文件仍可恢复；浏览器使用 IndexedDB 保存 Blob，空间不足明确提示“未保存”。项目按需加载，删除项目不删除外部原文件。
- 正常关闭与确认更新重启时，等待导入、导出、手势提交及待保存操作完成。保存失败时保留当前编辑状态并提示重试。
- 大幅面拼接优先尝试快速全彩无损 PNG，已满足上限即使用；简单平坦图片继续精细无损压缩，超限时沿用原高保真/等比降分辨率搜索。快速文件可能比最大压缩等级略大，像素和透明度完全相同，不添加填充。相同处理结果可直接复用为独立导出任务，不再重读原图和编码。
- 已有项目保留可恢复的原有尺寸、顺序、裁剪和位置，不在打开时重新贴合；下次导入才应用新规则。不删除原图或旧清单备份。

## 体积与画质

输出严格不超过设定大小。符合上限且无需修改的原始文件直接保留；调整尺寸或格式后，可以使用完整的设定预算，以优先保留画质、尽量接近上限。

PNG 先比较全彩无损编码的两种行过滤策略。不能达到上限时，在完整颜色空间中搜索受限像素变化：RGB 每通道最大误差为 2/255，透明度不变，保护平坦区域、平滑渐变和强边缘；候选需通过实际解码后的最大误差、RMSE 校验。仍然超限时，按用户确认的规则从原始像素等比降低分辨率，搜索符合上限的尺寸；不再要求用户增加上限，也不采用 256 色或明显降色来保留高像素数字。

JPEG 预算充足时使用 4:4:4 保留细彩色边缘；预算不足时用快速编码定位质量范围，比较解码后的像素误差，再用 mozjpeg 在局部范围细化。每种策略搜索最高适配质量，透明部分合成为白色。PNG 不改格式；自动降分辨率时明确显示实际尺寸与“等比调整”，设置的尺寸和原图保持不变。

主流程不添加体积填充，以实际编码文件字节数校验上限。

PNG 的编码误差以实际导出尺寸下的等比缩放像素为基准；降低分辨率会损失部分空间细节，不能称为原尺寸无损。严格 2.5:1 画布缩小时继续采用 5:2 整数尺寸，无裁切或透明填充。预览、单独导出与批量导出共用同一处理规则，以实际保存文件字节数验证上限。所有工作流忽略旧客户端的填充标志，不添加无意义字节凑大小。

最新体积回退验证、用户附件的 10 MB 实际输出及缩放损失对比见 [docs/png-budget.md](docs/png-budget.md)。

未改尺寸、格式且原文件已符合预算时直接复用原文件，不运行压缩编码；明确指定的尺寸或格式修改仍执行。PNG 像素分析只计算一次，复用最佳无损过滤策略并减少候选编码。编码缓存限 64 MiB / 256 条；快速修改设置会结束过时预览的后续合成/搜索，真实导出保留。实测 PNG 照片/纹理约快一倍，详细时延与像素差异见验证文档；大图第一次尝试极低上限仍可能较慢。旧版 docs/performance-0.4.1.md 使用调色板流程，不能代表本分支画质与耗时。

输入支持单帧 JPEG、PNG、WebP、AVIF、TIFF。单图 100 MB、队列 100 张/500 MB、目标最大 100 MB、总像素不超过 1 亿。不接受动画/多页文件，防止丢失帧。高位深图片暂不支持尺寸或格式转换。

## 自动更新

0.4.5 已通过 Gitee 的 a1meon_admin/halframe-releases 发布。桌面启动检查新版，先询问，再下载并确认重启；离线启动安静，点击版本号可手动检查。Mac 使用 Sparkle、Ed25519 签名更新包及免费 ad-hoc 应用签名，无需 Apple Developer Program；Windows 使用 NSIS。Gitee 大安装包采用经过校验的分片传输。首次安装和发布步骤见 [docs/auto-update.md](docs/auto-update.md)。

## 开发环境

需要 Node.js 22.15 或更新版本，建议 Node.js 24。

```sh
npm ci
npm run dev
```

浏览器预览与桌面共用真实处理引擎。浏览器预览导出会写入 `artifacts/browser-exports/`；桌面版使用原生目录选择器。

```sh
npm test
npm run build
npm run desktop
npm run smoke:desktop
npm run smoke:ui
npm run smoke:recovery
npm run smoke:optimization
npm run smoke:png-budget
npm run fixtures:stitch
npm run smoke:canvas
npm run smoke:canvas-fit
npm run smoke:canvas-resize
npm run smoke:split
npm run verify:quality -- /path/to/optional-original.png
```

## 打包

```sh
npm run pack:mac        # Apple Silicon DMG / ZIP
npm run pack:mac:intel  # Intel Mac DMG / ZIP
npm run pack:win        # Windows NSIS 安装程序
npm run pack:win:zip    # Windows 完整应用目录 ZIP
```

Windows ZIP 解压后运行「轻图.exe」，保留同目录资源和 DLL。本次开发不构建或发布安装包、不合并 main。签名材料缺失时保留嵌入公钥，由原发布环境在后续发布确认后签名。

桌面分发产物在 `release/`。本分支在 Windows 上执行 Electron 开发构建烟测及关闭重开检查；本次没有 Mac 实机、安装包安装或正式更新签名发布验证。历史发布记录见自动更新文档。

## 验证与结构

- `engine/`：图片编码、纯布局计算、原图合成、原子项目保存、体积与画质校验。
- `desktop/`：Electron 主进程和受限 preload，renderer 无 Node 权限。
- `src/`：压缩工作台、`stitch/` 拼接交互与 IndexedDB 图片 Blob/项目存储、关闭保存协调。
- `tests/`：目标字节、像素、透明度、EXIF、等比尺寸、并发缓存和重名文件保护。
- `design-qa.md`：源视觉与最终实现的检查记录。

样片及图标由内置 Image Gen 生成，工作区保留生成的 PNG 原始资源，`public/samples/*.jpg` 只作为测试素材，不在启动时自动加载。工具栏使用 Phosphor Icons 及自绘 SVG，压缩导航采用折角图片图标，应用图标为生成的蓝色折角图片形象。全部处理在本机进行，不上传图片。
