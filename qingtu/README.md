# 轻图

Mac / Windows 本地图片压缩与拼接工具。拖入图片，设置大小或分辨率，预览并导出。压缩模块底部是图片队列，拼接模块底部是整个画布的项目卡片。

本分支实现固定高度的人物拼接工作流、直接拖动换序、四边及四角关联裁剪、画布上分割、独立布局记忆、多项目自动保存恢复和全彩高保真 PNG。最新规则、真实截图与导出验证见 [docs/portrait-workflow.md](docs/portrait-workflow.md)，提速与原图分割基础见 [docs/split-and-speed.md](docs/split-and-speed.md)。0.4.6 已联合发布 Windows x64、Mac Apple Silicon 和 Mac Intel；见 [发行与验证记录](docs/release-0.4.6.md)。

## 使用

- 启动时图片队列为空，大小默认 10 MB，重置后也为 10 MB；可切换 KB。1 MB = 1,000,000 字节，1 KB = 1,000 字节。
- 未导入图片时尺寸显示 4K（3840 × 2160）；导入后显示原图尺寸、100% 缩放。格式默认 PNG，重置后仍为 PNG。
- 左侧纯图标导航，悬停或键盘聚焦显示功能名称；“图像拼接”进入真实工作台。切换模块保留各自图片、设置和预览；已完成的拼接预览不会因切换而重新合成/编码。右侧设置栏可收起。
- 蓝色立体按钮、按压回弹、菜单浮现、导入入场和完成反馈动效；系统开启减少动态效果时停用动画。
- 使用自动优化，没有模式切换。修改宽度、高度或缩放百分比即可调整分辨率；链条按钮锁定原图比例。
- 两个模块的导出格式只有 JPG、PNG，默认 PNG；旧项目的“自动”转为明确的 PNG。WebP 可导入，输出为 JPG 或 PNG。JPG 将透明背景合成为白色。
- 压缩预览提供原图、对比、处理后三种查看方式；拼接直接在画布编辑，右上角不再切换布局/处理后。两个模块的预览框、底部列表、大小、格式、文件夹与导出按钮保持相同位置。图片和缩略图以白底预览，PNG 导出仍保留透明度；Mac 顶栏使用系统原生窗口按钮。
- 保留原文件时标记“未改动”。预览分别来自原文件和真实导出文件，使用一致的采样边界；等待结果时不以原图充当结果。
- 选择文件夹后导出。重名文件自动追加编号，不覆盖源文件或已有输出。
- ⌘/Ctrl + O 添加图片；⌘/Ctrl + Shift + S 导出。批量处理可取消后续任务。

## 拼接

- 首次使用没有画布，中央显示“新建画布”按钮，底部也保留同名卡片；点击可创建，也可直接拖入原图自动创建一个画布并导入。删除最后一个或删除全部后保持无画布，重新打开仍显示中央新建按钮。已有项目照常自动恢复。

- 小窗口按当前可用空间放大显示画布，仅为当前显示的裁剪／分割控件留位置；普通查看不预留整个编辑面板。窗口变大后自动适配，导出继续使用设置的画布像素尺寸，调整窗口不会重新编码。

- 自由布局中的图片完全移出预览区后，工作区右下出现“显示全部”；点击后画布和所有越界图片一起显示，可从淡显图片直接拖回。“聚焦画布”恢复大画布预览。调整视图不会改变保存的图片位置、裁剪、大小或导出画布。

- 裁剪下方提供当前边的滑块和原图像素输入，开启关联时两侧一起调整；滑块向回拖到 0 可恢复完整内容，四边及四角直接拖动仍可用。一键优化默认将第 3 张顶部裁去 15%、左右各裁 100 个原图像素。按钮旁的设置面板有几张图就显示几个编号按钮，没有图就没有图片按钮；支持同时选择多张，并为每张分别设置顶部百分比、左右各裁像素。再次点击可取消该图的特殊裁剪，全部取消后统一左右裁剪。新设置随图片和画布保存，换序后仍跟随对应图片，点击一键优化才应用。选中的图片不再追加裁剪，其余图片按相同百分比左右居中裁剪以铺满当前画布；全部选中时，需由各自裁剪后的比例匹配画布。无法满足时说明原因，原图始终保留，已有项目参数和裁剪不会因默认值更新而自动改动。

- **画布高度固定，默认 2398 px**。导入图片按画布高度等比显示、向右追加；自动宽度随横排图片总宽变化，最多为高度的 2.5 倍且不超过 5999 px，默认最大为 5995×2398。达到上限后，继续放大图片只改变图片本身，越界内容淡显，最终只导出画布区域；不会把其他图片缩小或悄悄改掉原图裁剪。
- 支持四张独立图（正脸、侧脸为 3:4，正面全身、背面全身为 9:16），也支持两张已合成图（正脸＋侧脸、正面全身＋背面全身）。不自动识别角色或去头：选中正面全身图，在上下不联动时拖动上边裁剪即可去掉头部。裁剪后保持该图的显示高度与原有比例，调整宽度并重新衔接横排。
- 每边仍须为 1–5999 整数像素、长短边比不超过 2.5。自动宽度封顶后保留越界内容供编辑；非法手动尺寸或过窄布局明确提示并阻止导出，不补透明边来掩盖冲突。右侧保留 2.5:1、21:9、16:9、4:3、1:1 预设及独立宽高输入；选择后保持该画布尺寸，直到再次导入才按固定高度重新适配宽度。
- 横排、宫格、竖排首次进入时自动排列并贴合内容；手动指定过画布时，在该画布内等比排列。横排等高、竖排等宽；宫格每行等高、各行同宽，无空格或空洞，无法容纳时提示调整，不自动裁切图片。四种布局分别自动记住最后的**画布尺寸、图片位置和尺寸**，切回时恢复，点击当前布局不重排；自由首次保留当前变换。每次导入也会按各布局自己的相对位置重新贴合已访问的布局，避免切回后遗漏新图。裁剪与顺序仍由项目共用。
- 横排、竖排、宫格中直接拖动图片换序，显示轻量目标框；换序保留横排图片的裁剪、尺寸与原始导入顺序记录，不重置编辑。自由布局中拖动是移动，保留吸附。四种布局均支持四角与四边共八个缩放手柄，默认等比；按住 Shift 可独立调节宽高。画布高度保持固定，上下超出部分由画布裁切。缩放默认吸附到画布边缘、其他图片边缘和中心线，显示轻量辅助线；吸附不改变默认等比规则。画布外以 22% 透明度显示，选中框在前景；淡显、选中框和手柄都不进入导出。
- 所有导出边缘为矩形，无额外外边距、圆角遮罩或棋盘格；PNG 保留画布留空处和源图透明度，白色预览底仅用于显示。JPG 将透明区域合成为白色。
- 底部“图像”卡片展示整个画布，点击缩略图切换编辑，左上角勾选框独立选择要导出的画布，支持单选、多选及全选/取消全选。默认导出全部非空画布，手动选择后只导出勾选项；右侧按钮显示实际数量，未勾选时禁用。空画布不可勾选，切换画布或模块保留本次选择，重开应用恢复默认全选。右键卡片仍可直接单独导出或删除，删除前确认；列表右上角可确认删除全部，完成后显示“新建画布”。画布内不再显示添加/删除按钮；使用拖入或 ⌘/Ctrl+O 继续导入，Delete 移除选中图片。手动创建的空画布仍可点击“添加图片”，无画布时拖入图片会自动新建画布。右侧保留布局与导出设置，卡片小图持久化且不加载其他项目原图。
- 横排“一键优化”从完整原图重新计算，替换旧裁剪并横排铺满**当前画布比例**，画布尺寸保持不变。例如画布改为 2:1，就按 2:1 优化。选定图片执行设置的裁剪，其余三张在默认四图与默认参数示例中每侧裁约 3.95%，2:1 画布则约 16.07%。只有裁剪及图片位置、尺寸都已优化时才禁用；放大、缩小、Shift 拉伸或移动后可再次优化。非横排、无效画布或无法裁剪铺满时仍禁用；参数下拉仍可打开，修改后可重新优化。
- 画布右上角仅放置各自有背景的重置与“一键优化”，优化位于最右侧，采用简洁的向内收拢线条图标。优化弹窗显示真实裁剪、保存、布局预览阶段；保存与清晰布局预览完成后弹窗直接关闭，即可继续编辑，体积在后台计算。MB 就绪后显示真实文件大小，导出等待实际编码并验证上限。处理中关闭为禁用浅灰色，失败关闭为白底中性色并保留错误。重置先确认，确认按钮沿用主按钮蓝色，取消为白底。右侧布局依次为横排、宫格、竖排、自由。
- 选中图片，上方显示“裁剪／分割”。双击、右键编辑也打开同一套下方控件，不再弹出可拖动编辑窗。裁剪直接拖动图片四边及四个角，保留原图像素数值，下方滑块控制当前边并可拖回 0 恢复内容；下方按“左／联动／右”和“上／联动／下”排列。左右默认联动，上下默认独立，已有明确设置保留；仅高亮当前编辑方向组，当前组开启联动后两侧按钮同时选中，同步裁剪；切换方向不改变另一组的联动设置。裁剪编辑框在图片下方居中，靠近窗口边缘时保持可见。向外拖可恢复可用原图，四边裁剪可以同时保留。横排裁剪拖动时实时保持图片显示高度、排紧横排，同步更新自动画布宽度和尺寸显示，宽度仍受 2.5:1 上限约束；手动画布保持尺寸。拖动时固定视图缩放和画布原点，避免预览自动适配造成指针跳动。角点分别遵守左右、上下联动；裁剪默认吸附画布边缘、其他图片边缘和中心线，以及完整原图边界。关联按图片保存，纯设置变更复用编码结果。未编辑图片左右各预填 50 px，未修改不应用；直接拖动从实际裁剪开始，不带入预填值。首次切换到上下边会清掉未应用的左右预填。松手或数值修改后自动保存；拖动中 Escape 取消本次拖动，平时点击控件外或 Escape 关闭，正常退出会保存未松手的最新裁剪；重置清除该图四边裁剪。
- 点击图片上方“分割”，在完整原图上拖动分割线或设置数值，图片右下方显示“取消／确认”。水平横线分上下，垂直竖线分左右；确认前不改变项目，取消恢复原裁剪和位置。分割忽略已有裁剪并保留原图中心、缩放比例；两张共用不可变原图副本，确认不编码、不复制大图，可继续分割、缩放和裁剪。其他布局记忆同步替换父图位置，保存恢复使用同一源区域。
- 右上角重置先确认，清除裁剪、撤销放大或 Shift 拉伸，并恢复真正导入顺序。新导入图片记录导入时的显示宽高，自由布局恢复该大小并保留当前中心；横排、宫格、竖排重新衔接排列，各布局记住的放大状态也会清除。没有尺寸记录的旧图按当前画布高度等比恢复；拆分图片继承原图相应部分的导入尺寸。保留布局、手动画布和导出设置，自动画布宽度按既有规则更新。没有顺序记录的旧多图项目须由用户提供真实顺序，应用不会猜测。
- 拖动、缩放及裁剪边在 requestAnimationFrame 中只更新低分辨率画面，结束后自动保存并计算真实预览；键盘 Alt+方向键换序并按当前预设重新排列，自由模式下调整叠放顺序；普通方向键移动图片，Shift+方向键移动 10 px，Enter 编辑，Delete 移除。聚焦裁剪边时，对应方向键按 1 个原图像素调整，Shift 按 10 px 调整。
- 主按钮“导出 X 张图像”默认导出全部有内容的画布项目，空画布跳过且不计入 X；右键卡片可分别导出。每个项目独立保存图片、布局、位置、尺寸与导出设置。卡片和缩略图禁止原生拖动，内部缩略图文件不会被当作原图导入其他项目。编辑自动保存；桌面保管原图副本，移动原文件仍可恢复；浏览器使用 IndexedDB 保存 Blob，空间不足明确提示“未保存”。项目按需加载，删除项目不删除外部原文件。
- 正常关闭与确认更新重启时，等待导入、导出、手势提交及待保存操作完成。保存失败时保留当前编辑状态并提示重试。
- 大幅面拼接优先尝试快速全彩无损 PNG，已满足上限即使用；简单平坦图片继续精细无损压缩，超限时沿用原高保真/等比降分辨率搜索。快速文件可能比最大压缩等级略大，像素和透明度完全相同，不添加填充。相同处理结果可直接复用为独立导出任务，不再重读原图和编码。
- 已有项目保留原图、顺序、裁剪和图片变换；旧自动画布沿用保存的高度，宽度按新上限封顶，越界内容保留。手动画布保留指定尺寸，无效设置仍可恢复并修改。不删除原图或旧清单备份。

## 体积与画质

输出严格不超过设定大小。符合上限且无需修改的原始文件直接保留；调整尺寸或格式后，可以使用完整的设定预算，以优先保留画质、尽量接近上限。

PNG 先比较全彩无损编码的两种行过滤策略。不能达到上限时，在完整颜色空间中搜索受限像素变化：RGB 每通道最大误差为 2/255，透明度不变，保护平坦区域、平滑渐变和强边缘；候选需通过实际解码后的最大误差、RMSE 校验。仍然超限时，按用户确认的规则从原始像素等比降低分辨率，搜索符合上限的尺寸；不再要求用户增加上限，也不采用 256 色或明显降色来保留高像素数字。

JPEG 预算充足时使用 4:4:4 保留细彩色边缘；预算不足时用快速编码定位质量范围，比较解码后的像素误差，再用 mozjpeg 在局部范围细化。每种策略搜索最高适配质量，透明部分合成为白色。PNG 不改格式；自动降分辨率时明确显示实际尺寸与“等比调整”，设置的尺寸和原图保持不变。

主流程不添加体积填充，以实际编码文件字节数校验上限。

PNG 的编码误差以实际导出尺寸下的等比缩放像素为基准；降低分辨率会损失部分空间细节，不能称为原尺寸无损。严格 2.5:1 画布缩小时继续采用 5:2 整数尺寸，无裁切或透明填充。预览、单独导出与批量导出共用同一处理规则，以实际保存文件字节数验证上限。所有工作流忽略旧客户端的填充标志，不添加无意义字节凑大小。

最新体积回退验证、用户附件的 10 MB 实际输出及缩放损失对比见 [docs/png-budget.md](docs/png-budget.md)。

未改尺寸、格式且原文件已符合预算时直接复用原文件，不运行压缩编码；明确指定的尺寸或格式修改仍执行。PNG 像素分析只计算一次，复用最佳无损过滤策略并减少候选编码。编码缓存限 64 MiB / 256 条；快速修改设置会结束过时预览的后续合成/搜索，真实导出保留。实测 PNG 照片/纹理约快一倍，详细时延与像素差异见验证文档；大图第一次尝试极低上限仍可能较慢。旧版 docs/performance-0.4.1.md 使用调色板流程，不能代表本分支画质与耗时。

输入支持单帧 JPEG、PNG、WebP、AVIF、TIFF。单图 100 MB、队列 100 张/500 MB、目标最大 100 MB、总像素不超过 1 亿。不接受动画/多页文件，防止丢失帧。高位深图片暂不支持尺寸或格式转换。

0.4.6 已通过 Gitee 的 a1meon_admin/halframe-releases 发布。桌面启动检查新版，先询问，再下载并确认重启；离线启动安静，点击版本号可手动检查。Mac 使用 Sparkle、Ed25519 签名更新包及免费 ad-hoc 应用签名，无需 Apple Developer Program；Windows 使用 NSIS。Gitee 大安装包采用经过校验的分片传输。首次安装和发布步骤见 [docs/auto-update.md](docs/auto-update.md)。

## 打包

```sh
npm run pack:mac        # Apple Silicon DMG / ZIP
npm run pack:mac:intel  # Intel Mac DMG / ZIP
npm run pack:win        # Windows NSIS 安装程序
npm run pack:win:zip    # Windows 完整应用目录 ZIP
```

## 验证与结构

- `engine/`：图片编码、纯布局计算、原图合成、原子项目保存、体积与画质校验。
- `desktop/`：Electron 主进程和受限 preload，renderer 无 Node 权限。
- `src/`：压缩工作台、`stitch/` 拼接交互与 IndexedDB 图片 Blob/项目存储、关闭保存协调。
- `tests/`：目标字节、像素、透明度、EXIF、等比尺寸、并发缓存和重名文件保护。
- `design-qa.md`：源视觉与最终实现的检查记录。

样片及图标由内置 Image Gen 生成，工作区保留生成的 PNG 原始资源，`public/samples/*.jpg` 只作为测试素材，不在启动时自动加载。工具栏使用 Phosphor Icons 及自绘 SVG，压缩导航采用折角图片图标，应用图标为生成的蓝色折角图片形象。全部处理在本机进行，不上传图片。
